# ⏱ Multi Timer

Простое и удобное десктопное приложение для учёта времени задач.

Создано для работы с несколькими таймерами одновременно, быстрым запуском задач через шаблоны, ведением архива и выгрузкой данных в Excel.

---

## 🚀 Возможности

- До 12 таймеров одновременно
- Максимум 2 активных таймера
- Быстрый запуск через шаблоны
- Плановые и дополнительные задачи
- Откат времени таймера на 10 минут
- Уведомление, если таймер работает слишком долго
- Автоматическое добавление таймера в архив при удалении
- Перенос всех текущих таймеров в архив
- Статистика по архиву
- Выгрузка архива в Excel
- Автоматическое имя файла архива с датой
- Темная / светлая тема
- Работа в системном трее
- Frameless UI (кастомное окно)
- Проверка и установка обновлений

---

## ⚙️ Логика работы

### Таймеры

- Таймер можно запустить только с названием
- Одновременно могут работать максимум 2 таймера
- При запуске 3-го таймера один из активных автоматически ставится на паузу
- Название нельзя менять во время работы таймера
- Активный таймер можно откатить на 10 минут назад
- Если таймер работает долго, приложение показывает напоминание

### Типы задач

- Плановая
- Дополнительная

Тип задачи используется в архиве, статистике и Excel-выгрузке.

---

## 📦 Шаблоны

- Быстрое создание и запуск таймера
- Ограничение: до 7 шаблонов
- При выборе шаблона таймер запускается сразу
- Шаблоны сохраняются локально

---

## 📊 Архив и экспорт

### Архив

В архив попадают завершённые или удалённые таймеры.

Для каждой записи сохраняется:

- Дата
- Название задачи
- Время
- Тип задачи

### Выгрузка в Excel

Архив можно выгрузить в `.xlsx`.

Файл сохраняется с датой в названии, например:

```text
archive_2026-10-06.xlsx
```
